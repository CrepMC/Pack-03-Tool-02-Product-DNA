# 03 — Revision Request to T01

T02 không tự sửa image. Khi evidence thiếu:
- `reason_code`;
- `asset_id`;
- `json_path`;
- `region`;
- `problem`;
- `requested_evidence`;
- `suggested_non-destructive_action`;
- `blocking`.

Ví dụ: neckline crop mất 30% → yêu cầu user cung cấp ảnh rõ hơn hoặc T01 đề xuất crop/contrast nếu user approve.
