# 09 — UI Specification

## Main regions

1. Header + project/version.
2. Upstream status card.
3. Asset strip with role badges.
4. Product candidate selector.
5. Product DNA field groups.
6. Evidence inspector.
7. Conflicts & questions.
8. Consistency locks preview.
9. Approve & Export.

## Field row

Hiển thị:
- label;
- value;
- confidence badge;
- status icon;
- evidence count;
- critical lock icon;
- edit action.

## Evidence inspector

Click field → mở thumbnail/crop reference, asset ID, view angle, observation. Không cần expose chain-of-thought.

## Accessibility

Keyboard navigable, color không là tín hiệu duy nhất, confidence có text, error focus management, mobile layout không che approve button.
