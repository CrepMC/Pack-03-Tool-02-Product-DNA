# Project Baseline

Pack này bám theo quy trình dự án: asset được chuẩn hóa trước, Product DNA trở thành source of truth, các tool camera/motion/environment/cinematic hoạt động độc lập, QA kiểm tra và Prompt Optimizer sửa có kiểm soát. Trọng tâm là giảm lỗi đổi cổ áo, biến dạng màu/form, tự thêm/bớt vật phẩm và hallucination.
